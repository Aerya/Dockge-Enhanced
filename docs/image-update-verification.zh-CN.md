# 验证镜像更新

[English](image-update-verification.md) · [Français](image-update-verification.fr.md) · [Deutsch](image-update-verification.de.md) · [Español](image-update-verification.es.md) · [简体中文](image-update-verification.zh-CN.md)

> 仅为本分支提案，不属于已发布版本。

ImageWatcher 可从运行中的容器找回本地标签丢失的镜像，在 Compose 执行后验证每个目标副本，并将不一致报告为失败。无法验证的更新不会推进时间。下载的镜像在更新中断或未验证后受到 24 小时清理保护。

预期的不可变镜像 ID 在拉取后、重建前记录。每个普通目标服务必须保持副本数量；所有副本必须运行、不能处于 unhealthy 状态，并使用该 ID。共享网络命名空间的服务也包含在内。滚动更新保留自身的健康和连接排空检查；等待排空完成时仍明确显示为未验证，不推进时间。

本地标签丢失时，通过运行中容器的镜像进行检测。镜像仓库或检查错误保持为未知，绝不标为最新。确认的不一致是失败；无法完成检查则显示为未验证。这两种结果均不计为成功更新，也不推进 lastUpdated。

清理与镜像更新互斥。拉取前，Enhanced 持久保存目标引用的保护，之后记录下载镜像的 ID。中断或未验证的更新保留此保护 24 小时，重启后仍有效。验证成功仅释放该操作的保护。保护期从尝试或下载时间开始，而非镜像构建时间；到期后可按正常规则清理未使用镜像。

堆栈时间标为“最近操作”，并提供说明提示。它描述对堆栈的一次操作，可能只影响一个服务，不保证全部服务均为最新。每个镜像的结果仍可在 Watcher 历史中查看。暂停、排除、维护时间窗口及回滚机制均保留。
