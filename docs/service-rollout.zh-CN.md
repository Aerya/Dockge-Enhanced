# 服务不中断更新

[English](service-rollout.md) · [Français](service-rollout.fr.md) · [Deutsch](service-rollout.de.md) · [Español](service-rollout.es.md) · [简体中文](service-rollout.zh-CN.md)

默认禁用。Enhanced 先启动新容器，再停止旧容器：同一个应用会暂时同时运行两份，并不是运行两个 Enhanced 实例。应用必须允许这种并行运行，不能产生数据冲突、重复任务或不兼容的数据库迁移。Enhanced 无法自动判断这一点：健康检查只能确认容器是否响应，不能证明两份应用同时运行是安全的。

如果没有使用兼容的 Traefik 模式，可以准备一个中继：这是一个小型中间容器，保持访问地址不变，并将连接送到正确版本。助手只修改草稿，将发布端口和 Traefik/PlugNPiN 标签移到中继。请检查后明确部署。如果代理指向主机 IP 和该端口，可保留原目标；如果指向应用服务名，请改为中继服务名。Enhanced 不会自动修改您的代理配置。连接来源显示为中继地址；不暴露管理 API。

启用前请先确认兼容性。应用容器数量会暂时翻倍，请预留足够的 CPU/RAM。固定容器名和共享可写卷会被拒绝。中继会增加一个容器和一个配置卷。首次安装会将访问端口移到中继，可能短暂中断访问。之后请使用“更新”；Recreate、重启和回滚不保证保持现有连接。仅支持 TCP，不支持 UDP/QUIC，也不保证所有场景零中断。

## 部署

如果现有 Docker 发现与连接摘除满足要求，可使用原生 Traefik。否则，在服务编辑器中输入**内部 TCP 端口**，点击**准备可选中继**。保存和部署前检查草稿：发布端口及 Traefik/PlugNPiN 标签将移至独立中继服务。首次部署可能中断流量。使用主机 IP 和发布端口的代理目标可保持不变；使用应用服务名的目标需要明确改为中继服务名。

中继使用 Nginx stream，不终止 TLS，也不暴露管理 API。HTTP、TLS、WebSocket 可通过 TCP；不支持 UDP/QUIC。不需要 NPM、Caddy 或 HAProxy API 凭据。协议兼容不等于认证每一种产品和版本。目前原生集成面向 Traefik。中继拥有持久配置卷和专用网络/别名，使用期间不要删除。请将此配置与 stack 一同备份。

## 恢复与限制

需要健康检查及额外 CPU/RAM。固定容器名、共享可写卷和命名空间依赖仍不兼容。助手会拒绝不明确的端口变量/范围、profiles 和 extends，不会自行猜测。保留已有 CPU/RAM 限制。应用看到的连接来源为中继 IP；需要原始客户端 IP 的应用须另行检查受信任代理配置。

更新应用时不会重建中继，新流量只会切换到健康的替代容器。超过前台等待时间的连接保持打开；旧 worker 代全部退出后会自动移除旧容器。长连接本身不会让新流量退回旧版本。中继自身重启、Recreate 和显式回滚仍会造成中断。

请更新关联实例两端。受限账户需拥有应用**及其中继**的更新权限。打开编辑器不会修改配置；准备中继仅修改草稿。禁用服务不中断更新不会拆除中继或还原端口，这一迁移需明确检查。不会自动修改生产代理配置。

服务不中断更新不添加额外 Compose 覆盖或临时标签；配置不变时再次 Deploy 会保留容器。Docker 修改前会原子保存操作日志。中断后，未提交的事务会取消；已提交事务只继续移除记录中的旧 ID。删除前重新检查身份和健康，替代容器异常时可把流量恢复到已记录且健康的旧代。等待中的 Stack 禁止并发修改，但被动等待连接不占用全局更新锁。有意退出流量的旧副本不会触发自动修复。操作日志必须保存在 Enhanced 持久数据及备份中，不要为解除等待而删除日志。身份变化或存留副本不健康时暂停删除并显示警告。历史记录表示应用更新当时延后了旧容器移除，服务界面显示当前状态。中继启动时使用已验证的 Compose 初始配置替换无效路由，保留有效路由。
